# Testeiya documentation

Testeiya is an AI assistant for QA. Chat with it to analyze your test suites, find coverage gaps, review test quality, and create or improve test cases — across your Testomat.io projects or any local folder. It runs as a **desktop app**, a **web app**, and a **terminal CLI** from one codebase.
